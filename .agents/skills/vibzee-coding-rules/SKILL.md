# Vibzee coding rules

Apply these rules to every code change in Vibzee.

- Keep code compact and readable.
- Avoid adding helper functions used only once. Keep one-use logic at its call site.
- Limit edits to code and behavior directly affected by the request.
- Keep the implementation easy to explain and add only the complexity the task requires.
